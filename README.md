# 🏀 Hooplab for iOS (SwiftUI)

Нативная версия баскетбольного обучающего приложения **Hooplab** для iOS (iPhone / iPad), написанная на чистом **SwiftUI** (iOS 16.0+).

---

## 📱 Функционал приложения

1. **Главная (Home):**
   - Брендированный заголовок с отслеживанием стриков (`🔥 Стрик дней`) и опыта (`⚡ XP`).
   - Карточка «Тренировка дня» с возможностью быстрого старта в один тап.
   - Счётчики прогресса: количество завершённых тренировок, суммарное время и 2K-рейтинг игрока (OVR).
   - Быстрый запуск баскетбольного IQ-квиза.
   - Категории упражнений и карусель популярных тренировок.

2. **Каталог тренировок (Workouts):**
   - 49 упражнений с полной поддержкой русского и английского языков.
   - Живой поиск по названию и описанию.
   - Фильтрация по категориям: *Все, Броски, Дриблинг, Защита, Техника, Физика, Тактика*.
   - Фильтрация по уровню сложности: *Все, Начальный, Средний, Продвинутый*.
   - Кнопка добавления в Избранное (`❤️`).

3. **Детальный экран упражнения (Exercise Detail):**
   - Красочный баннер с категорией, уровнем и иконкой.
   - Кнопка быстрого перехода к интерактивной тренировке («Начать тренировку»).
   - Индикаторы подходов и времени отдыха.
   - Пошаговые иллюстрированные чек-листы выполнения.
   - Задействованные группы мышц.
   - Советы тренера (Coach's Tips) и список типичных ошибок.

4. **Интерактивный таймер тренировки (Workout Timer):**
   - Смена фаз: **Выполнение подхода** ➔ **Интервал отдыха** ➔ **Завершение**.
   - Анимированный круговой таймер с секундным отсчётом.
   - Тактильный виброотклик (Haptic Feedback) и звуковые сигналы при смене фаз и отсчёте последних 3 секунд.
   - Начисление опыта (XP) и сохранение тренировочной сессии в профиль.

5. **Баскетбольный IQ-Квиз (Basketball Quiz):**
   - 10 официальных вопросов по правилам FIBA и NBA (24 секунды, двойное ведение, позиция PG, высота кольца 3.05м, пик-н-ролл, лимиты фолов, правило 3 секунд, бокс-аут, 8 секунд зоны, дуга 6.75м).
   - Подсветка правильных (зелёный) и неверных (красный) ответов с haptics.
   - Раскрывающееся поле с подробным разбором правил.
   - **Непрерывный переход:** кнопка **«Следующий вопрос ▶»** сразу переключает на следующий вопрос прямо в том же окне без необходимости закрывать модалку!
   - Экран завершения с подсчётом очков, наградой XP и возможностью сыграть снова.

6. **Площадки (Courts):**
   - Стритбольные корты (Лужники, Парк Горького / Музеон, Таганка, ВДНХ) с адресами, типами покрытия, количеством колец и статусом освещения.

7. **Профиль игрока (Player Profile):**
   - Индивидуальная карточка в стиле NBA 2K с расчётом OVR (60–99).
   - Радар 5 ключевых навыков: Броски, Проходы, Защита, Плеймейкинг, Атлетизм (прокачиваются по мере завершения тренировок).
   - Достижения (Badges): *Первый бросок, В ударе, Снайпер, Легенда площадки*.
   - Выбор позиции на площадке (PG, SG, SF, PF, C).
   - Переключение языка приложения (Русский / English).

## 🛠 Архитектура проекта

- **Чистый SwiftUI:** без сторонних тяжёлых библиотек (Zero external dependencies). Собирается за секунды на любой машине.
- **Haptic & Sound:** `UIImpactFeedbackGenerator`, `UINotificationFeedbackGenerator`, `AudioToolbox`.

## 🚀 Как собрать готовый `.ipa` без Mac (через GitHub Actions)

Так как на Windows нет Xcode, процесс сборки автоматизирован через бесплатный macOS-раннер GitHub:

1. Создай новый репозиторий на [GitHub](https://github.com/new) (например, `hooplab-ios`).
2. В терминале в папке `hooplab-ios` выполни:
   ```bash
   git init
   git add .
   git commit -m "Initial iOS SwiftUI commit"
   git branch -M main
   git remote add origin https://github.com/<твой-юзернейм>/hooplab-ios.git
   git push -u origin main
   ```
3. Перейди во вкладку **Actions** в репозитории на GitHub:
   - Воркфлоу **«Build iOS IPA (Hooplab)»** запустится автоматически.
   - Сборка на сервере Apple Silicon займёт около 1–2 минут.
4. В блоке **Artifacts** скачай архив **`Hooplab-iOS-IPA`**, внутри которого лежит готовый **`Hooplab.ipa`**!

## 📲 Как установить `.ipa` на iPhone с твоим сертификатом

Так как у тебя есть персональный сертификат разработчика / профиль:

### Способ 1: Через утилиты прямо на iPhone (Scarlet / Esign / GBox / TrollStore)
1. Отправь скачанный `Hooplab.ipa` на телефон (через Telegram / iCloud / AirDrop).
2. Открой установщик (например, **Esign** или **Scarlet**).
3. Выбери опцию **«Подписать» (Sign)** и укажи свой сертификат (`.p12` + `.mobileprovision`).
4. Нажми **«Установить»** — приложение появится на домашнем экране iPhone как обычное приложение из App Store!

### Способ 2: Через ПК (AltStore / Sideloadly)
1. Подключи iPhone по проводу к ПК.
2. Открой **Sideloadly** или **AltStore**.
3. Перетащи файл `Hooplab.ipa`, введи свой Apple ID (или выбери сертификат) и нажми **Start**.
